# 알려진 제한 사항

- 한 사용자는 한 캠페인에서 한 국가만 담당합니다. 공동 운영은 지원하지 않습니다.
- 전쟁·군사 전투, 결제, 음성·영상 채팅, 채팅 파일 첨부는 MVP 범위가 아닙니다.
- 채팅은 일반 텍스트와 한 단계 답글만 지원합니다.
- 실시간 채팅은 장기 실행 Node 서버와 PostgreSQL 연결이 필요합니다.
- 이미지 지도 가져오기는 등거리 원통도법 이미지를 기준으로 셀 중심 색상을 판독합니다.
- 검은색·투명 픽셀은 국경으로 제외하며 국가 팔레트와 일치하지 않는 색상은 기존 소유권을 유지합니다.
- 실제 AI 공급자 품질과 비용은 운영 키와 모델 설정에 따라 달라집니다. 개발 기본값은 Fake 공급자입니다.
- 모바일에서도 열람할 수 있지만 지도 대량 편집은 데스크톱 사용을 권장합니다.
